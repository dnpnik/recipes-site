# Пряная кухня

Статический сайт домашних рецептов с приправами: каталог, поиск по ингредиентам и специям,
пересчёт порций, избранное и тёмная тема. Без сборки, без зависимостей — чистые HTML, CSS и JS.

**Живая версия:** https://dnpnik.github.io/recipes-site/

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | Разметка: шапка, поиск, фильтры, сетка карточек, диалог рецепта |
| `styles.css` | Тёплая пряная палитра, светлая и тёмная темы, адаптивная сетка |
| `app.js` | Загрузка данных, поиск, фильтры, избранное, пересчёт порций |
| `data/recipes.json` | 15 рецептов: ингредиенты, шаги, специи, советы |
| `.nojekyll` | Отключает обработку Jekyll на GitHub Pages |

## Как добавить рецепт

Добавьте объект в массив `recipes` в `data/recipes.json`:

```json
{
  "id": "krem-sup-gribnoy",
  "title": "Крем-суп из белых грибов",
  "category": "Супы",
  "time": 45,
  "servings": 4,
  "difficulty": "Средне",
  "emoji": "🍄",
  "hue": 25,
  "description": "Короткое описание для карточки.",
  "spices": ["тимьян", "чёрный перец"],
  "tags": ["осень"],
  "ingredients": [
    { "name": "белые грибы", "amount": 400, "unit": "г" },
    { "name": "сливки 20 %", "amount": 200, "unit": "мл" },
    { "name": "соль", "amount": 1, "unit": "щепотка" }
  ],
  "steps": ["Первый шаг.", "Второй шаг."],
  "tip": "Совет по специям."
}
```

`hue` — тон плитки карточки в HSL (0–360): 25 — тыквенный, 45 — шафран, 320 — сливовый.
`amount` может быть `null` — тогда в списке покажется только `unit`, например «по вкусу».

Категория в карточках-фильтрах появляется автоматически из поля `category`.

## Локальный запуск

Данные загружаются через `fetch`, поэтому нужен HTTP-сервер, а не `file://`:

```bash
python -m http.server 8080
# открыть http://localhost:8080
```

## Горячие клавиши

- `/` — фокус в поле поиска
- `Esc` — закрыть карточку рецепта

## Публикация

Сайт собирается из ветки `main` (корень репозитория) через GitHub Pages.
После пуша в `main` достаточно обновить страницу через минуту.
